# Calculadora Simples em Node.js

Este é um projeto básico de uma calculadora feita em **Node.js**, que realiza operações matemáticas a partir de dados inseridos pelo usuário no terminal.

---

## Funcionalidades

* ➕ Soma
* ➖ Subtração
* ✖️ Multiplicação
* ➗ Divisão
* ⚠️ Tratamento de divisão por zero

---

## Tecnologias utilizadas

* Node.js
* Módulo nativo `readline`

---

## Exemplo de uso

```
Digite o primeiro número: 10
Digite o segundo número: 2
Escolha a operação (+, -, *, /): /

Resultado: 5
```

---

## Conceitos praticados

* Entrada de dados via terminal
* Uso do `readline`
* Estrutura condicional (`switch`)
* Conversão de string para número (`parseFloat`)
